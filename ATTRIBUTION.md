# Template attribution — Ava malt (Set A)

into the public domain under **CC0 1.0 Universal**
(https://creativecommons.org/publicdomain/zero/1.0/).

Sources were downloaded, converted to black stroke/fill coloring-page SVGs
(square `viewBox="0 0 100 100"`), and lightly cleaned for toddler use
(crop, thicken, remove frame / dung / flies where needed).
